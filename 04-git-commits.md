# Assignment 4 - Git Commits

## Objective
To learn how to initialize a Git repository, stage files, and create a commit.

## Steps Performed
1. Checked the Git version using `git --version`.
2. Initialized a repository using `git init`.
3. Checked repository status using `git status`.
4. Staged files using `git add .`.
5. Created the first commit using `git commit -m "Add initial assignment files"`.
