# Assignment 5 - GitHub Push

## Objective
To connect a local Git repository to GitHub and upload project files.

## Steps Performed
1. Created a new GitHub repository named `Assignment-Web-Development`.
2. Connected the local repository to GitHub using `git remote add origin`.
3. Verified the remote URL using `git remote -v`.
4. Uploaded local files using `git push -u origin master`.

## GitHub Repository
https://github.com/KuldeepOnGit/Assignment-Web-Development

## Result
Successfully connected the local Git repository to GitHub and pushed the assignment files to the remote master branch.
