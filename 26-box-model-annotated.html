CSS Box Model

Every HTML element is displayed as a box made up of different layers.

Example Box

Content appears inside this area.

The Four Parts of the Box Model

  1. Content: The text, image, or other information inside an element.
  2. Padding: Space between the content and the border.
  3. Border: The line surrounding the content and padding.
  4. Margin: Space outside the border that separates the element from others.
