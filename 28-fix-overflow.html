2. Responsive Images

Images should not exceed the width of their parent container. Use max-width: 100% and height: auto.

3. Wide Tables

A wide table can scroll horizontally within its wrapper instead of making the entire page overflow.

4. Important CSS Fixes

overflow-wrap: anywhere;

max-width: 100%; height: auto;

overflow-x: auto;

Use the appropriate fix for the content. Avoid applying overflow: hidden everywhere, because it may cut off useful information.
