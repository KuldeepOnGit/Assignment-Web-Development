CSS Design Tokens

Consistent Design Using Reusable CSS Variables

What Are Design Tokens?

Design tokens are reusable values for colors, fonts, spacing, borders, and other design properties. In CSS, custom properties allow us to store these values in one place.

For example, var(--color-primary) uses the primary color defined inside the :root selector.

Color Tokens

Primary color: --color-primary

Secondary color: --color-secondary

Accent color: --color-accent

Muted text uses the muted color token.

Spacing and Components

This card uses reusable spacing, border-radius, font, and shadow tokens to keep the design consistent.

Why Use Design Tokens?

  • Keep colors and spacing consistent.
  • Change a design value in one place.
  • Make CSS easier to maintain.
  • Reuse the same values across components.
