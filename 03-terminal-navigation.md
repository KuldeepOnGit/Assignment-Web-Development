# Assignment 3 - Terminal Navigation

## Objective
To practice terminal commands for creating and navigating folders and files.

## Commands Practiced

1. `cd ~` - Navigate to the home directory.
2. `mkdir website` - Create a website folder.
3. `mkdir website\css` - Create a CSS folder.
4. `mkdir website\images` - Create an images folder.
5. `New-Item website\index.html -ItemType File` - Create an HTML file.
6. `New-Item website\css\style.css -ItemType File` - Create a CSS file.
7. `tree website /F` - Display the folder structure.
8. `cd website\css` - Navigate to the CSS folder.
9. `cd ..` - Move to the parent directory.
10. `Rename-Item index.html home.html` - Rename a file.
11. `code .` - Open the current folder in VS Code.

## Result
Successfully created folders and files and practiced terminal navigation commands.
