Understanding Position

position: relative; keeps an element in the normal document flow while allowing it to be offset.

position: absolute; positions an element relative to its nearest positioned ancestor.

z-index controls the stacking order of positioned elements. A higher value generally places an element above a lower value in the same stacking context.
