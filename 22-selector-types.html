CSS Selector Types

1. Element Selector

The element selector targets HTML elements by their tag name. For example, the h1 selector styles all h1 headings.

2. Class Selector

This paragraph uses the highlight class. Class selectors begin with a dot (.) in CSS.

3. ID Selector

The main heading uses the ID "main-heading". ID selectors begin with a hash (#) in CSS.

4. Group Selector

The h2 and h3 elements share the same color because they are selected together using a comma.

This is an H3 heading

5. Universal Selector

The universal selector (*) matches all elements. Here, it applies box-sizing: border-box.

6. Descendant Selector

The selector .content p targets paragraphs located inside an element with the content class.
