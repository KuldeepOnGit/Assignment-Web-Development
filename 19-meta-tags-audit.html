HTML Meta Tags Audit

Meta tags provide information about a webpage to browsers and search engines. Most meta tags are placed inside the <head> section.

Meta Tags Checklist

Meta Tag Purpose Status
charset Defines character encoding. Present
viewport Supports responsive layouts. Present
title Defines the page title shown in browser tabs. Present
description Summarizes the page for search results. Present
author Identifies the page author. Present
robots Provides crawling and indexing instructions. Present

Audit Notes

  • Use a unique and descriptive title for each page.
  • Write a clear and relevant meta description.
  • Include the viewport tag for mobile devices.
  • Keep the character encoding declaration near the beginning of the head.
  • Meta keywords are generally ignored by major search engines such as Google.
Important: This checklist documents the tags included in this example. It does not automatically inspect a live website or guarantee search engine rankings.
